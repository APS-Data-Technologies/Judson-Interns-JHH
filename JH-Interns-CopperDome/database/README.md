# Database - JH-Interns-CopperDome

This directory contains database schema references and seed data for Copper Dome Concierge.

## Overview

Use this folder to store:
- PostgreSQL schema definitions.
- SQL migration snippets.
- Seed data for development and testing.

## Usage

Add SQL files here to define the database tables and relationships for concierge bookings, guests, staff, and event logs.

## Notes

This scaffold does not include a live database instance. Use the backend Django migrations and database configuration to create and manage your Postgres schema.
